# magassoni-dre

Host publico do **dashboard DRE Magassoni** cifrado.

O conteudo publicado (branch `gh-pages`) e um unico HTML **cifrado com StatiCrypt**:
nenhum dado financeiro em claro fica exposto. Para visualizar o dashboard e
necessario informar a senha. O HTML e gerado e publicado automaticamente por um
GitHub Actions em outro repositorio.

Nao ha segredos, tokens nem dados sensiveis neste repositorio.
